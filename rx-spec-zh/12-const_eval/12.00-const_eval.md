# 常量上下文

常量上下文是常量项初始化器、数组类型长度和数组重复长度。每一种都使用下文定义的受限形式，包括对常量项的引用。

## 允许的形式

```grammar,constants
ConstValue -> INTEGER_LITERAL | `true` | `false` | ConstantPath | `-` Magnitude | `(` ConstValue `)`

Magnitude -> INTEGER_LITERAL | ConstantPath | `(` Magnitude `)`

ConstantPath -> PathInExpression
```

`ConstantPath` 必须解析为常量项，可以直接解析，也可以通过诸如 `LIMIT`、`Config::LIMIT` 或 `Self::LIMIT` 的关联常量路径解析。指向局部变量、函数或其他值的路径是静态形式错误。在此文法中，`Magnitude` 表示不带前导负号的整数字面量或常量路径，而不是无符号目标类型。负数形式需要带符号整数类型。这些形式允许 `123`、`LIMIT`、`-LIMIT`、`(-1)`、`-(1)`、`((true))` 以及有效的后缀和基数。

每个常量上下文包含整数字面量或布尔字面量、常量项引用、可选地带括号的负整数或负常量，或者包围另一种允许形式的圆括号。任何其他表达式都是静态形式错误。

```rust,ignore
const COUNT: usize = 64;
const COPY: usize = COUNT;
const SENTINEL: i32 = (-1);
const ENABLED: bool = (true);

fn main() {
    let data: [i32; COUNT] = [0; COUNT];
    let n: usize = COPY; // ordinary expressions may also read a constant
}
```

常量路径通过其所引用的常量项递归求值。常量项可以在使用它的项之前或之后声明。依赖图必须是无环的：自引用或诸如 `A -> B -> A` 的间接环是编译错误。编译器必须在尝试求值所涉及的常量之前检测出环。

## 类型与范围

常量路径具有其目标项所声明的类型和值。常量项初始化器具有所声明的期望类型；数组长度是常量值，期望类型为 `usize`。

字面量类型化与有符号最小值情形遵循[整数字面量规则](../11-expressions/11.01-literal-expr.md#integer-typing-and-range)。超出范围的字面量在[整数字面量范围保证](../01-undefined-behavior/01.00-undefined-behavior.md#integer-literal-range)下是未定义行为。普通类型错误和受限形式错误仍然是编译错误。

[传播排除](../10-types/10.00-types.md#coercion-sites-and-expected-types)同样适用于此：`const N: isize = -1;` 是未定义行为，因为它需要期望类型穿过一元负号传播。应改为写 `-1isize`。`const N: i32 = -1;` 是有效的，因为字面量 `-1` 默认是 `i32`。

`[expr; 4]` 中的元素表达式是受[数组重复](../11-expressions/11.07-array-expr.md#array-expressions)约束的普通表达式。只有其长度属于常量上下文。

对普通运行期表达式进行常量传播和折叠仍然是允许的优化。它们不会把这些表达式变成 const 上下文，也不会改变其算术语义。
