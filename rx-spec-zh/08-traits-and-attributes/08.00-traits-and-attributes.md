# Trait 和属性

Rx 支持四个[内置 trait](08.01-builtin-traits.md)的派生属性：`Copy`、`Clone`、`PartialEq` 和 `Eq`。不支持用户定义的 trait、trait 约束和显式 trait 实现。

## 属性文法

```grammar,attributes
OuterAttribute -> `#` `[` DeriveAttribute `]`

DeriveAttribute -> `derive` `(` (DeriveName (`,` DeriveName)* `,`?)? `)`

DeriveName -> `Copy` | `Clone` | `PartialEq` | `Eq`
```

这是完整的属性文法。零个或多个外部属性（[OuterAttribute]）可以位于顶层具名字段 [Struct] 之前。不支持其他构造上的属性、内部属性（`#![...]`）以及其他属性名称或派生名称。

派生列表可以为空，或带有尾随逗号。结构体上的所有派生属性共同构成所请求的同一 trait 集合；在同一属性内或同一结构体的多个属性之间指定重复 trait 是编译错误。每个请求的 trait 必须满足其[要求](08.01-builtin-traits.md#trait-capability-summary)。

```rust,ignore
#[derive(Clone)]
#[derive(Copy, PartialEq, Eq,)]
struct Point { x: i32, y: i32 }
```
