# 内置 trait

编译器识别 `Copy`、`Clone`、`PartialEq` 和 `Eq`。结构体通过指定[派生属性](08.00-traits-and-attributes.md#attribute-grammar)来实现它们。仅有的内置 trait 操作是 `.clone()`、`==` 和 `!=`；排序和算术运算受[运算符](../11-expressions/11.04-operator-expr.md)约束。

## Copy

**功能。** 读取位置会复制 `Copy` 值并移动任何其他值。这适用于初始化、赋值、按值参数和接收者、返回以及字段读取。移动使其源在重新初始化之前不可用；它从不创建隐式别名。`Copy` 是标记 trait，不引入任何方法。

副本在语义上是独立的。复制共享引用会复制该引用，而不是其目标。机器级地址传递约定必须保持按值语义。当没有可观察行为变化时，移动可以重用存储。

测试排除读取未初始化值、移动后使用、双重移动、无效部分移动，以及从借用内容或数组索引中移动非 `Copy` 值。不要求编译器诊断这些所有权违规，但必须正确支持跨分支、穿过字段以及提前返回期间的合法移动。

**要求。** 派生 `Copy` 要求结构体的每个字段都实现 `Copy`，并且还必须在结构体上显式派生 `Clone`。即使按位复制可以实现 `Clone`，也必须显式请求派生 `Copy`。

**示例。** 复制一个小值，同时保持原值可用。

```rust,ignore
#[derive(Clone, Copy)]
struct Point { x: i32, y: i32 }

fn main() {
    let original = Point { x: 1, y: 2 };
    let mut copied = original;
    copied.x = 9;
    print_i32(original.x); // 1
}
```

## Clone

**功能。** `Clone` 提供 `fn clone(&self) -> Self`。派生的 `Clone` 实现递归地克隆所有字段和数组元素，以产生独立的值。标量和共享引用被复制；共享引用的目标不会被克隆。拥有的堆容器的克隆语义在[容器克隆](../14-heap/14.00-heap.md#clone-and-equality)中定义。

显式 `.clone()` 使用[方法查找](../11-expressions/11.10-method-call-expr.md#method-lookup)。如果多个候选方法匹配同一候选接收者类型（例如固有方法与派生的 `clone` 方法竞争），则该方法调用会导致未定义行为。

**要求。** 派生 `Clone` 要求每个字段都是 `Clone`。可变引用不是 `Clone`。

**示例。** 复制拥有的堆数据，使每个值可以独立更改。

```rust,ignore
#[derive(Clone)]
struct Buffer { value: Box<i32> }

fn main() {
    let original = Buffer { value: Box::<i32>::new(7) };
    let mut cloned = original.clone();
    *cloned.value = 9;
    print_i32(*original.value); // 7
}
```

## PartialEq

**功能。** `PartialEq` 启用 `==` 和 `!=`，它们借用其操作数。标量值按值比较；数组逐元素比较；派生的结构体比较每个对应字段；引用比较其指向对象而不是其指针地址。填充字节被忽略，因此整对象 `memcmp` 通常无效。`Box` 和 `Vec` 遵循[容器相等性](../14-heap/14.00-heap.md#clone-and-equality)。

**要求。** 派生 `PartialEq` 要求每个字段都是 `PartialEq`。两个操作数必须共享实现 `PartialEq` 的完全相同的源类型；相等运算符不执行隐式类型强制转换，也不会从对侧操作数推断无后缀整数字面量的类型。因此 `1 == 1i32` 是有效的，而 `1 == 1u32` 根据[跨类型相等性保证](../01-undefined-behavior/01.00-undefined-behavior.md#cross-type-equality)属于未定义行为。

**示例。** 比较记录而不消费它们。

```rust,ignore
#[derive(PartialEq)]
struct Reading { value: i32 }

fn main() {
    let first = Reading { value: 7 };
    let second = Reading { value: 7 };
    let same = first == second; // true
    let different = first != second; // false; both remain usable
}
```

## Eq

**功能。** `Eq` 将相等性标记为等价关系：自反、对称和传递。它不引入新操作；相等比较继续使用 `PartialEq`。

**要求。** 派生 `Eq` 要求每个字段都是 `Eq`，并且必须为结构体显式请求 `PartialEq`。

**示例。** 声明记录标识符具有基于等价的相等性。

```rust,ignore
#[derive(PartialEq, Eq)]
struct Key { id: i32 }

fn same_key(left: &Key, right: &Key) -> bool {
    left == right // compares id fields
}
```

## Trait 能力摘要

| 类型 | `Copy` | `Clone` | 具有相同源类型的 `PartialEq` / `Eq` |
| --- | --- | --- | --- |
| 整数、`bool` | 是 | 是 | 两者 |
| `&T` | 是 | 是 | 要求 `T` 具有相应能力 |
| `&mut T` | 否 | 否 | 要求 `T` 具有相应能力 |
| `[T; N]` | 如果 `T` 是 `Copy` | 如果 `T` 是 `Clone` | 要求 `T` 具有相应能力 |
| 结构体 | 有效的显式派生 | 有效的显式派生 | 有效的显式派生 |
| `Box<T>`, `Vec<T>` | 否 | 如果 `T` 是 `Clone` | 要求 `T` 具有相应能力 |

零大小数据遵循[零大小数据保证](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)。即使在求值递归类型定义时，trait 能力验证也必须终止，同时仍强制每个字段的 trait 要求。例如，只要所有其他字段满足相应的 trait 要求，`struct Node { children: Vec<Node> }` 就可以派生 `Clone`、`PartialEq` 和 `Eq`。
