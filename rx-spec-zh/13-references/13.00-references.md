# 引用与存储期

## 引用标注

[引用类型](../10-types/10.02-pointer.md)指定被引用类型、可变性和可选的生命周期。它们可以出现在结构体字段、数组元素类型、函数参数和返回类型以及泛型容器类型实参中。

```rust,ignore
struct View<'a> { value: &'a i32 }

fn choose<'a>(a: &'a i32, b: &'a i32, first: bool) -> &'a i32 {
    if first { a } else { b }
}
```

## 生命周期有效性

对于受支持的构造，声明、标注、实参、约束和省略遵循 Rust 2021 的[泛型参数](https://doc.rust-lang.org/reference/items/generics.html)和[生命周期省略](https://doc.rust-lang.org/reference/lifetime-elision.html)规则。在[生命周期有效性保证](../01-undefined-behavior/01.00-undefined-behavior.md#lifetime-validity)下，无效的生命周期使用是未定义行为（即，测试保证生命周期有效，编译器不需要诊断生命周期错误）。

编译器可以[在解析后丢弃生命周期语法](../04-grammar/04.00-grammar.md#syntax-that-may-be-discarded-after-parsing)；它不必实现生命周期检查或推断。引用类型、其可变性及其所指对象仍然是程序语义的一部分。

函数参数列表中每个被省略的生命周期都被赋予一个不同的生命周期参数。如果恰好存在一个输入生命周期（省略的或显式的），则该生命周期被赋予所有省略的输出生命周期。如果存在多个输入生命周期，但其中一个属于引用接收者（`&self` 或 `&mut self`），则该接收者的生命周期被赋予所有省略的输出生命周期。任何其他带有省略输出生命周期的函数签名都是有歧义的，需要显式标注。占位符生命周期 `'_` 在 Rust 2021 省略规则允许的地方被接受。

正确的标注描述有效性；它们绝不会延长局部变量、临时值或堆对象的存储期。

## 借用规则

要求进行普通的类型和可变性检查：可变借用需要可变位置，共享引用不能被可变地再借用，通过共享引用进行的写入必须被拒绝。不要求进行借用数据流分析，因为测试保证实际借用和所有权有效。

有效程序可以使用多个共享引用、不相交的可变引用以及具有更短生命周期的再借用。一旦其再借用失效，父可变引用就再次可用。将可变引用传递给 `&mut` 参数会隐式再借用所指对象。

```rust,ignore
let mut x = 10;
let r = &mut x;
{
    let reborrow: &mut i32 = r; // child reborrow
    *reborrow = 20;
}
*r = 30;                        // parent reference is usable again
```

引用不需要运行期生命周期标记、引用计数或所有权检查。优化仍然必须尊重别名和再借用；不同的引用值不必表示不同的地址。

## 存储与实现

受支持的 Rust 2021 局部变量和临时值作用域定义了源代码层面的有效性。除非被移动或以其他方式失效，局部变量在其作用域结束前保持有效。遮蔽会创建一个新绑定，而不会结束旧值的存储期。语句临时值通常持续整个语句，符合条件的 `let` 初始化器会获得 Rust 的临时生命周期延长。

符合规范的基线实现可以为每次调用分配固定的栈存储，并保留到返回为止。递归调用需要独立的栈帧，而循环体内变量的栈存储不必在迭代之间累积（即，槽位存储可以跨迭代复用）。只要可观察行为和有效引用得以保持，实现就可以提升值、复用槽位或消除存储。

保留字节并不会使悬空的源代码引用变得有效。常量提升是可选的，测试不会返回指向被提升字面量或其他具有程序生命周期的临时值的引用。

<details>
<summary>被排除的引用执行</summary>

测试绝不：

- 在其目标失效、以使其失效的方式移动、被释放或被重新分配之后使用引用。
- 返回并使用指向被调用者局部变量或生命周期不够长的临时值的引用。
- 通过冲突的活动共享借用和可变借用访问重叠的存储。
- 在冲突的子再借用活动期间使用父可变引用。
- 从被借用的内容中移动非 `Copy` 数据，或复用已被移动的可变引用。
- 引用未初始化、未对齐、类型不正确或其他无效的数据。

共享引用可以互为别名，不相交的可变借用保持有效。使用运行期索引执行的容器和数组访问也必须满足这些借用排他性规则。

</details>

容器特定的失效遵循 [Box 和 Vec 存储规则](../14-heap/14.00-heap.md#storage-and-references)。省略堆释放（泄漏堆存储）不会延长源代码层面的引用有效性。
