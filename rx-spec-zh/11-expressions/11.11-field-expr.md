# 字段访问表达式

r[expr.field.syntax]
```grammar,expressions
FieldExpression -> Expression `.` IDENTIFIER
```

`.` 之后的标识符选择一个已声明的具名字段；未知字段是编译错误。

结果是其可变性跟随其基的位置。值基只求值一次，并在需要时物化为临时值。读取字段遵循 Copy/移动规则。参见[位置和值](11.00-expressions.md#places-and-values)和[引用存储期](../13-references/13.00-references.md)。

## 自动解引用

字段访问会反复解引用引用和 `Box`，直到到达第一个包含具名字段的结构体类型。这些是[强制转换类型](../10-types/10.00-types.md#coercion-types)下列出的内建解引用步骤。对于 `boxed: Box<S>`，`boxed.field` 访问所包含 `S` 的字段。字段访问不会插入借用。

```rust,ignore
struct Point { x: i32, y: i32 }
let p = Box::<Point>::new(Point { x: 10, y: 20 });
println_i32(p.x);               // automatically dereferences Box<Point> to access field x
```

穿过共享引用会使字段变为只读。持有 `&mut S` 的不可变绑定仍然可以给出对 `S` 字段的可变访问。进一步的调整遵循[解引用规则](11.04-operator-expr.md#borrow-dereference-and-assignment)。无论解引用多少次，基都只求值一次。
