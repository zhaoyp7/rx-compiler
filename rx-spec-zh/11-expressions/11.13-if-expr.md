# if 表达式

r[expr.if.syntax]
```grammar,expressions
IfExpression ->
    `if` Conditions BlockExpression
    (`else` (BlockExpression | IfExpression))?

Conditions -> Expression _except an unparenthesized [StructExpression] at the condition/body boundary_
```

```rust,ignore
fn choose(flag: bool) -> i32 {
    if flag { 1 } else { 2 }
}
```

条件表达式必须求值为类型 `bool`；可以省略外围括号。支持 `else if` 链；执行时按顺序求值条件，并执行第一个求值为 `true` 的条件的主体（或者，如果存在 `else` 块且没有条件匹配，则执行该块）。条件/主体边界处的结构体构造需要按下文所述显式定界。

当条件/主体边界处未加括号的 `Name {` 可能开始一个结构体字面量时，将 `{` 视为后续块的开头。要把这样的结构体构造放在条件中，需显式定界，例如 `if (S { flag: true }).flag { ... }`。像 `if check(S { flag: true }) { ... }` 这样的函数参数已经被定界。该规则并不意味着 if 之后的每个花括号都开始其后续块：`if { true } { ... }` 的条件是一个块值，后面是一个单独的后续块。

有 `else` 时，外围期望类型通过[一对一强制转换](../10-types/10.00-types.md#coercion-sites-and-expected-types)应用于两个结果分支。如果没有期望类型，则[LUB 强制转换](../10-types/10.00-types.md#least-upper-bound-coercions)找出它们的共同类型。具有 never 类型 `!` 的分支总是可以强制转换为另一分支的类型。如果没有 `else`，该表达式具有单元类型 `()`，且 `then` 块的期望类型为 `()`。
