# 字面量表达式

r[expr.literal.syntax]
```grammar,expressions
LiteralExpression -> INTEGER_LITERAL | `true` | `false`
```

字面量表达式产生整数或布尔值。[INTEGER_LITERAL] 定义了整数字法单元的拼写。

注意，单元 `()` 使用的是 [UnitExpression]。

## 整数类型与范围

整数后缀固定其类型。没有后缀时，如果提供了期望的整数类型，就使用它；否则使用 `i32`。需要通过二元运算符、一元运算符或共享/可变借用进行传播的类型推断属于[未定义行为](../10-types/10.00-types.md#coercion-sites-and-expected-types)。根据后续操作数或之后的用法来选择字面量的类型同样会导致[未定义行为](../10-types/10.00-types.md#coercion-sites-and-expected-types)。运行时整数宽度在[类型](../10-types/10.00-types.md)中规定。

前导负号构成 [NegationExpression]。一元负号字面量情形允许有符号最小值：`-2147483648i32` 使用大小为 2147483648 的整数字法单元，并表示有效的 i32 最小值。带圆括号的负字面量（如 `-(2147483648i32)`）遵循同一规则。

在通过后缀、期望类型或 `i32` 回退选定类型之后，值超出该类型可表示范围的整数字面量表现出未定义行为；请参阅[整数字面量范围保证](../01-undefined-behavior/01.00-undefined-behavior.md#integer-literal-range)。

```rust,ignore
let a = 42;             // i32 by default
let b = 42u32;          // u32 by explicit suffix
let c: usize = 42;      // usize from expected type
let min = -2147483648i32; // valid i32 minimum
```
