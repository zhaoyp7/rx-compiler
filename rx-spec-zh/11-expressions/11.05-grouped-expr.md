# 分组表达式

r[expr.paren.syntax]
```grammar,expressions
GroupedExpression -> `(` Expression `)`
```

带圆括号的表达式具有其内部操作数的值和类型，并保留位置（place）状态。圆括号可以在语句边界强制进入表达式上下文，并可以消除条件中结构体构造的歧义，或消除 `<` 或 `<<` 之前强制转换的歧义。

```rust,ignore
let mut x = 5;
(x) = 10;                     // a parenthesized place remains an assignable place
let y = (1 + 2) * 3;          // grouping overrides default operator precedence
```

空圆括号 `()` 构成 [UnitExpression] 所描述的单元表达式。
