# 块表达式

r[expr.block.syntax]
```grammar,expressions
BlockExpression -> `{` Statements? `}`

Statements ->
      Statement+
    | Statement+ ExpressionWithoutBlock
    | ExpressionWithoutBlock
```

块包含若干[语句](../09-statements/09.00-statements.md)和一个可选的最终表达式，由花括号包围。语句按源代码顺序执行。

块的类型和结果值按如下方式确定：

- 如果块有尾表达式（不带分号的最终表达式），则该表达式决定块的类型，并在到达时决定其结果值。
- 如果块没有尾表达式且正常完成，则其类型为 `()`，求值为 `()`。
- 如果块中的每条执行路径都通过控制流转移（`return`、`break` 或 `continue`）提前退出，则该块不会正常完成，并具有 [never 类型](../10-types/10.05-never.md) `!`。如果某些路径提前退出，而另一条路径在没有尾表达式的情况下到达末尾，则该块正常完成，类型为 `()`。

```rust,ignore
fn select(flag: bool) -> i32 {
    let base = if flag { 10 } else { 20 };
    { base + 1 } // the inner block and function body both yield an i32
}
```

尽管形式文法允许在语句序列下解析不带分号的 [ExpressionWithBlock](11.00-expressions.md)，但在块的最终位置，它充当块的尾表达式并决定块的值。

块和尾随语句的解析遵循[语句边界规则](../09-statements/09.00-statements.md#statement-boundary)；局部变量存储遵循[存储持续时间](../13-references/13.00-references.md#storage-and-implementation)。
