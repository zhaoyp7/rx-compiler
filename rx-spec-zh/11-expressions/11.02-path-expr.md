# 路径表达式

r[expr.path.syntax]
```grammar,expressions
PathExpression -> PathInExpression
```

路径表达式解析非限定值名称、`self` 或关联项（如 `Point::LIMIT`）。路径形式和命名空间规则在[路径](../06-names/06.01-paths.md)和[名称](../06-names/06.00-names.md)中规定。

函数路径充当调用目标。在有效程序中，`Box` 和 `Vec` 构造函数是对 [PathExpression] 的调用，其容器段携带 [GenericArgs]；省略类型实参表现出[未定义行为](../14-heap/14.00-heap.md#builtin-signatures)。

## 函数值

将函数用作值（如 `let f = helper;`）在[测试保证](../01-undefined-behavior/01.00-undefined-behavior.md#test-guarantees)下属于未定义行为。这适用于普通函数、关联函数和方法以及内建函数。不要求提供函数值表示或诊断。调用函数并使用其结果遵循普通的[调用规则](11.09-call-expr.md)。

```rust,ignore
fn helper() -> i32 { 42 }

let result = helper();          // valid: calling a function path
// let f = helper;              // undefined behavior: function item used as a first-class value
```
