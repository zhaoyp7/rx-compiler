# return 表达式

r[expr.return.syntax]
```grammar,expressions
ReturnExpression -> `return` Expression?
```

`return expression` 对其操作数求值，并使用复制/移动语义从当前函数返回该值。`return;` 返回单元值 `()`。当执行在没有提前返回的情况下到达函数体末尾时，函数尾表达式提供返回值。在所有情况下，返回的值必须与函数声明的返回类型兼容。

```rust,ignore
fn absolute(x: i32) -> i32 {
    if x < 0 {
        return -x;              // explicit early return
    }
    x                           // tail expression return
}
```

类型和可达性参见 [Never 类型](../10-types/10.05-never.md)。
