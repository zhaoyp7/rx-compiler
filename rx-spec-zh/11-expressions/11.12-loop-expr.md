# 循环表达式

## while 和 loop

```grammar,expressions
LoopExpression -> InfiniteLoopExpression | PredicateLoopExpression

InfiniteLoopExpression -> `loop` BlockExpression

PredicateLoopExpression -> `while` Conditions BlockExpression

BreakExpression -> `break` Expression?

ContinueExpression -> `continue`
```

`while condition { ... }` 在每次迭代之前重新求值一个 `bool` 条件，并求值为单元值 `()`。条件周围可以省略括号。`loop { ... }` 重复执行，直到控制流离开它；`break` 的值决定循环表达式的结果类型。两种形式的主体块都必须与单元类型 `()` 类型兼容；[发散](../10-types/10.05-never.md)的主体是兼容的。主体块中非单元的尾表达式不会成为循环表达式的值。因此，`while false { 1 }` 和 `loop { 1 }` 会导致编译期类型错误，而 `loop` 表达式可以通过 `break value;` 产生一个值。

`break;` 以单元值退出最近的循环。带值的 break 要求目标是 `loop`。循环的期望类型通过[一对一强制转换](../10-types/10.00-types.md#coercion-sites-and-expected-types)应用于其所有 break 值；如果没有期望类型，则[LUB 强制转换](../10-types/10.00-types.md#least-upper-bound-coercions)找出它们的共同类型。`continue;` 开始最近外围循环的下一次迭代（包括重新求值 `while` 条件）。在循环之外使用 `break` 或 `continue` 是编译错误。

出现在 while 条件中的 break 或 continue 必须以内嵌在该条件内部的循环为目标。以包含它的 while 或任何外层循环为目标是编译错误。例如，`while loop { break false; } {}` 是允许的。语法上的循环嵌套决定目标。

```rust,ignore
fn until(limit: i32) -> i32 {
    let mut n = 0;
    loop {
        if n == limit { break n; }
        n += 1;
    }
}
```

关于 `loop` 表达式何时具有 never 类型，参见[Never 类型](../10-types/10.05-never.md#loop-expressions)；关于控制流离开块后仍然适用的检查，参见[不可达代码](../10-types/10.05-never.md#unreachable-code)。
