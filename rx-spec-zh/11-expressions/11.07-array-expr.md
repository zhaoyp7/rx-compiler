# 数组表达式和数组索引表达式

## 数组表达式

r[expr.array.syntax]
```grammar,expressions
ArrayExpression -> `[` ArrayElements? `]`

ArrayElements ->
      Expression (`,` Expression)* `,`?
    | Expression `;` ConstValue
```

数组表达式要么显式列出其元素，要么将某个元素表达式重复一个由 [ConstValue] 指定的常量次数。显式列出的元素按[普通求值顺序](11.00-expressions.md#evaluation-order)求值。数组重复语法（`[elem; len]`）对其元素表达式求值一次，并重复所得的值；如果长度大于 1，元素类型必须实现 `Copy`，而不仅仅是 `Clone`。重复长度表达式按照[常量上下文规则](../12-const_eval/12.00-const_eval.md#typing-and-range)求值。空数组字面量和长度为零的重复表达式在语法上是有效的，但对零大小数组数据的任何使用在[零大小数据规则](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)下都是未定义行为。

```rust,ignore
let list = [1, 2, 3];           // explicit element list: [i32; 3]
let repeated = [0; 5];          // repetition: [i32; 5]
```

期望的数组类型通过[一对一强制转换](../10-types/10.00-types.md#coercion-sites-and-expected-types)将其元素类型提供给每个列出或重复的元素表达式。如果没有期望类型，则[LUB 强制转换](../10-types/10.00-types.md#least-upper-bound-coercions)会找出共同的元素类型。

## 数组索引表达式

r[expr.array.index.syntax]
```grammar,expressions
IndexExpression -> Expression `[` Expression `]`
```

### 索引操作数类型

索引的期望类型为 `usize`，因此未加后缀的字面量索引被推断为 `usize`。任何具有独立确定类型的索引表达式都必须具有类型 `usize`。

具有 never 类型 `!` 的索引操作数在[测试保证](../01-undefined-behavior/01.00-undefined-behavior.md#test-guarantees)下表现出未定义行为。这同时适用于数组和 `Vec`，例如 `data[return]` 和 `data[loop {}]`。

### 被索引的位置

索引会反复解引用引用和 `Box`，直到到达第一个数组或 `Vec`，使用[强制转换类型](../10-types/10.00-types.md#coercion-types)下列出的内建步骤。

基表达式位于 `[index]` 之前，并且只求值一次。如果它求值得到一个值而不是一个已有的位置（例如函数调用返回的数组），则在需要访问其元素时，该值会被物化到临时存储中。临时位置的不可变性和存储期遵循[临时位置规则](11.00-expressions.md#temporary-places)。

数组索引投影出一个元素位置，而不会插入对数组的借用。其可变性遵循[位置规则](11.00-expressions.md#places-and-values)。`Vec` 索引遵循单独的[可变访问规则和示例](../14-heap/14.00-heap.md#indexing-and-mutable-access)。

在有效执行中，数组索引必须保持在其固定长度之内。不要求运行时边界检查和 panic 处理。读取元素遵循[复制/移动语义](../08-traits-and-attributes/08.01-builtin-traits.md#copy)，包括通过数组索引进行非 Copy 移动的测试排除。Vec 的访问和移除遵循 [Vec 操作规则](../14-heap/14.00-heap.md#vec-operations)。

```rust,ignore
let mut data: [i32; 4] = [0; 4];
data[2] = 7;
println_i32(data[2]);
```

## 数组方法

固定数组的内建 `.len()` 的接收者为 `&self`，并返回其长度作为 usize。当数组按值传递时，整个数组被复制（如果是 [`Copy`](../08-traits-and-attributes/08.01-builtin-traits.md#copy)）或作为单个聚合体移动；数组参数永远不会退化或转换为指针。
