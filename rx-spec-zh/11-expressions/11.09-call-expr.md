# 调用表达式

r[expr.call.syntax]
```grammar,expressions
CallExpression -> Expression `(` CallParams? `)`

CallParams -> Expression ( `,` Expression )* `,`?
```

调用参数遵循[普通求值顺序](11.00-expressions.md#evaluation-order)，并根据声明的参数类型和[复制/移动规则](../08-traits-and-attributes/08.01-builtin-traits.md#copy)传递。被调用者必须解析为一个已声明的函数、关联函数或内建项。最后一个参数之后可以有一个可选的尾随逗号。

关联方法也可以作为 `Type::method(receiver, ...)` 调用，其接收者作为普通的第一个参数提供。该形式使用普通参数强制转换，而不是方法调用自动引用。`Box` 和 `Vec` 构造函数调用使用相同的调用语法；在容器路径段上省略显式类型参数是[未定义行为](../14-heap/14.00-heap.md#builtin-signatures)。

```rust,ignore
fn add(a: i32, b: i32) -> i32 { a + b }

struct Counter { val: i32 }
impl Counter {
    fn new() -> Counter { Counter { val: 0 } }
    fn inc(&mut self) { self.val += 1; }
}

let sum = add(1, 2);
let mut c = Counter::new();
Counter::inc(&mut c);           // fully qualified call syntax without autoref
```
