# 单元表达式

```grammar,expressions
UnitExpression -> `(` `)`
```

表达式 `()` 构造单元值。

单元值 `()` 是函数或控制流表达式在没有产生返回值的情况下完成时的结果。将单元值存储在变量中、将其作为实参传递，或将其嵌入聚合或堆数据，在[零大小数据保证](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)下表现出未定义行为。

```rust,ignore
fn log_status() {
    // implicitly evaluates to ()
}

log_status();                    // evaluates to the unit value () and discards it
```
