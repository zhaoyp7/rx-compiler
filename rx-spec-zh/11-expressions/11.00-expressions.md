# 表达式与求值

```grammar,expressions
Expression -> ExpressionWithoutBlock | ExpressionWithBlock

ExpressionWithoutBlock ->
      LiteralExpression
    | PathExpression
    | OperatorExpression
    | GroupedExpression
    | ArrayExpression
    | IndexExpression
    | UnitExpression
    | StructExpression
    | CallExpression
    | MethodCallExpression
    | FieldExpression
    | ContinueExpression
    | BreakExpression
    | ReturnExpression

ExpressionWithBlock ->
      BlockExpression
    | LoopExpression
    | IfExpression
```

表达式形成整数、布尔和单元值；解析名称与关联路径；构造 Box/Vec 值、数组和具名字段结构体；访问字段和带索引的元素；调用函数和方法；应用运算符；并通过块、if/while/loop 以及 return/break/continue 控制执行。圆括号对表达式进行分组。堆操作在 [Box 和 Vec](../14-heap/14.00-heap.md) 中规定。

## 求值顺序

普通操作数在包含它的运算之前从左到右求值。这包括调用实参、数组元素、结构体字段初始化器、比较、算术和索引。结构体字段按源代码顺序求值，而不是按声明或布局顺序。

[赋值](11.04-operator-expr.md#evaluation-order)、[短路逻辑](11.04-operator-expr.md#comparison-and-logic)、[数组重复](11.07-array-expr.md#array-expressions)和控制流的专门规则规定了哪些操作数会被求值以及按什么顺序求值。

优化必须保留可观察效果，包括 I/O 和通过引用进行的写入。

## 位置与值

位置（place）表示存储：变量、解引用、字段、带索引的数组或 `Vec` 元素，或带圆括号的位置。读取位置会根据其类型复制或移动其值。赋值要求可变位置，借用求值为包含该位置地址的引用。

可变局部变量可以被赋值。解引用 `&mut T` 会产生可变位置，除非是穿过共享引用到达的；解引用 `&T` 则不会。

以下块是相互独立的示例。未使用 `mut` 声明的绑定可以持有一个 `&mut T` 并修改其目标，但不能重定向到另一个目标：

```rust,ignore
let mut x = 1;
let mut y = 2;
let p = &mut x;
*p = 3;        // valid: changes x, not the binding p
p = &mut y;    // compile error: p is not a mutable binding
```

让绑定可变即可允许这两种操作：

```rust,ignore
let mut x = 1;
let mut y = 2;
let mut p = &mut x;
*p = 3;        // valid: changes x
p = &mut y;    // valid: redirects p to y
*p = 4;        // valid: changes y
```

共享引用不允许修改其目标，即使该目标声明为可变：

```rust,ignore
let mut x = 1;
let p = &x;
*p = 2;        // compile error: p gives shared access to x
```

此外，通过指向 `&mut T` 的共享引用无法恢复可变访问：

```rust,ignore
let mut x = 1;
let p = &mut x;
let shared = &p;
**shared = 2;  // compile error: reaching x crosses the shared reference
```

### 临时位置

诸如 `values` 这样的局部变量命名现有的存储。诸如 `make_array()` 这样的值表达式产生一个值，但不命名存储位置。当某个运算需要为该值提供一个位置时，该值会被保存在临时存储中。这称为*将临时量具现化*（materializing a temporary）。它适用于字段和索引的基址、显式借用的值，以及需要借用的方法接收者。

每当包含它的表达式被求值时，该值表达式就求值一次。该结果用于字段、元素、借用或方法调用；获取其地址不得再次对它求值。例如，对 `make_array()[0]` 进行索引会调用 `make_array()` 一次，该调用的任何副作用也只发生一次。

临时量可以在没有具名 `let mut` 绑定的情况下以可变方式使用。对于函数 `make_array() -> [i32; 2]`，以下操作是有效的：

```rust,ignore
make_array()[0] = 7;          // writes an element of the temporary array
Vec::<i32>::new().push(5);    // borrows the temporary vector as &mut self
let p = &mut 3;              // borrows a temporary integer
*p = 4;                     // modifies that integer
```

同一规则允许对任何返回的、包含该字段的结构体执行 `make().field = value`。现有位置仍遵循其自身的可变性规则：使用不可变局部变量或共享引用作为基址不会创建它的可变副本。赋值仍然需要位置表达式；`1 = 2` 和 `1 += 2` 是无效的。块以普通的复制/移动语义产生值。

<details>
<summary>临时量生命周期（可选背景）</summary>

临时量通常在其所在的语句期间保持有效。某些 `let` 初始化器会将其存储持续时间延长到所在块的末尾。在此示例中，初始化器中的显式借用延长了返回数组的生命周期：

```rust,ignore
fn make_array() -> [i32; 2] {
    println_i32(1);
    [10, 20]
}

fn main() {
    let r = &mut make_array()[0];
    *r = 99;
    println_i32(*r);
}
```

这会打印 `1`，然后打印 `99`，各占一行。该调用只运行一次，其返回的数组占用临时存储，`r` 指向其第一个元素。该数组一直有效，直到 `main` 的块结束。

从普通函数或方法调用返回引用本身并不会延长实参临时量的生命周期。例如，使用上面的 `make_array` 函数：

```rust,ignore
fn first(values: &mut [i32; 2]) -> &mut i32 {
    &mut values[0]
}

fn example() {
    let r = first(&mut make_array()); // the temporary array ends at this semicolon
    *r = 99; // excluded lifetime violation: r would refer to expired storage
}
```

最后一个示例不在[生命周期有效性保证](../01-undefined-behavior/01.00-undefined-behavior.md#lifetime-validity)的范围内；编译器无需诊断它。符合规范的实现可以将临时存储保留到函数返回，或在可观察行为和有效引用得以保留时将其优化掉，如[引用](../13-references/13.00-references.md#storage-and-implementation)所述。保留存储不会使本来无效的源代码引用变为有效。

</details>

## 优先级

以下各组从最强到最弱排列。同一行中的运算符共享优先级。

| 组 | 结合性 |
| --- | --- |
| 路径、字面量、分组 | 基本形式 |
| 字段和方法访问、调用、索引 | 后缀 |
| 一元 `-`、`!`、`*`、`&`、`&mut` | 前缀 |
| `as` | 左 |
| `*`、`/`、`%` | 左 |
| `+`、`-` | 左 |
| `<<`、`>>` | 左 |
| `&` | 左 |
| `^` | 左 |
| <code>&#124;</code> | 左 |
| `==`、`!=`、`<`、`<=`、`>`、`>=` | 不能在不加圆括号的情况下链式使用 |
| `&&` | 左 |
| <code>&#124;&#124;</code> | 左 |
| `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`^=`、<code>&#124;=</code>、`<<=`、`>>=` | 右 |
| `return`、带值的 `break` | 消耗其后的表达式 |

块/语句的消歧还遵循[语句](../09-statements/09.00-statements.md#statement-boundary)。
