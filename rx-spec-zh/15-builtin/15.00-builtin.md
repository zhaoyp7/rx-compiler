# 内建 I/O 与程序入口

## 程序入口

每个可执行程序都有一个顶层入口函数：

```rust,ignore
fn main() -> () {
    println_i32(42);
}
```

返回类型标注可以省略。`main` 函数具有空参数列表且没有泛型参数。

程序入口调用该源函数，并在该初始调用完成后返回状态 0。推荐的实现为源函数提供一个唯一的、经过名称修饰的内部符号，并导出一个作为 `main` 的 C ABI 包装器。该包装器调用源函数并返回有符号 32 位值 0。等效的降级实现必须保持这些行为，如[后端契约](../16-backend/16.00-backend.md#symbols-entry-and-runtime)所规定。

程序使用下面的 I/O 函数打印它们的答案。

## I/O 函数

以下接口记法描述了内建签名：

```rust,ignore
fn get_i32() -> i32;
fn print_i32(value: i32) -> ();
fn println_i32(value: i32) -> ();
```

`get_i32` 从标准输入读取一个有符号十进制 `i32`。测试输入保证包含足够的、在范围内的合法整数，以 ASCII 空白分隔；格式错误的输入和输入过早结束均被排除。`print_i32` 写出有符号十进制表示，不带任何额外字符。`println_i32` 写出相同的表示，后跟一个换行字节（`'\n'`，`0x0A`）。

参数是普通的 `i32` 值。另一种整数类型的值需要显式转换（例如 `print_i32(x as i32)`）。单元结果可以作为表达式语句丢弃；它们不允许普通的零大小绑定。

这三个函数构成源码可见的 I/O 接口。学生可以使用所提供的运行时，也可以在后端契约下实现一个兼容的运行时。
