# 记法

## 文法

以下记法用于 *Lexer* 和 *Syntax* 文法片段：

| 记法          | 示例                      | 含义                                   |
|-------------------|-------------------------------|-------------------------------------------|
| CAPITAL           | IDENTIFIER, INTEGER_LITERAL        | 词法分析器产生的词法单元             |
| _ItalicCamelCase_ | _LetStatement_, _Item_        | 语法产生式                  |
| `string`          | `x`, `while`, `*`             | 精确的字符                    |
| x<sup>?</sup>     | `mut`<sup>?</sup>             | 可选项                          |
| x<sup>\*</sup>    | _OuterAttribute_<sup>\*</sup> | x 出现 0 次或多次                            |
| x<sup>+</sup>     |  _Statement_<sup>+</sup>     | x 出现 1 次或多次                            |
| x<sup>a..b</sup>  | HEX_DIGIT<sup>1..6</sup>      | x 重复 a 到 b 次                   |
| Rule1 Rule2       | `fn` _Name_ _Parameters_      | 按顺序排列的规则序列                |
| \|                | `i32` \| `u32`, Block \| Item  | 选择（匹配备选项之一） |
| `[ ]`              | `[b B]`                       | 所列字符中的任意一个              |
| `[ - ]`            | `[a-z]`                       | 该范围内字符中的任意一个        |
| `~[ ]`             | `~[b B]`                      | 除所列字符外的任意字符       |
| ~`string`         | ~`\n`, ~`*/`                  | 除该序列外的任意字符      |
| ( )               | (`,` _Parameter_)<sup>?</sup> | 对项进行分组                              |
| U+xxxx            | U+0060                        | 单个 Unicode 字符                |
| \<text\>          | \<any ASCII char except CR\>  | 对应该匹配内容的英文描述 |
| Rule <sub>suffix</sub> | IDENTIFIER_OR_KEYWORD <sub>_except `crate`_</sub> | 对前一条规则的修改 |

顺序组合的优先级高于 `|` 选择。

## 字符串表产生式

某些规则，包括[一元运算符][unary operators]、[二元运算符][binary operators]和[关键字][keywords]，被定义为字面字符串表。在语法产生式中，字面字符串引用隐式匹配词法分析产生的对应词法单元。参见[词法单元][tokens]。

</details>

## 文法可视化

文法产生式出现在定义它们的章节中。词法规则使用大写名称；语法规则使用大小写混合的名称。每个文法块下方的按钮显示其[语法图][syntax diagram]，其中矩形表示非终结符，圆角矩形表示终结符。

[syntax diagram]: https://en.wikipedia.org/wiki/Syntax_diagram

## 公共产生式

以下是文法中使用的公共定义。

r[input.syntax]
```grammar,lexer
CHAR -> <a 7-bit ASCII source character>

SPACE -> U+0020

TAB -> U+0009

LF -> U+000A

CR -> U+000D
```
