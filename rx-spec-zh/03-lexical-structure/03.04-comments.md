# 注释

r[comments.syntax]
```grammar,lexer
@root COMMENT -> LINE_COMMENT | BLOCK_COMMENT

LINE_COMMENT -> `//` ~LF*

BLOCK_COMMENT -> `/*` ( BLOCK_COMMENT | BLOCK_CHAR )* `*/`

BLOCK_CHAR -> CHAR _not at the start of `/*` or `*/`_
```

注释支持行注释（`//`）和可嵌套的块注释（`/* ... */`）两种形式，并充当空白。行注释在 LF 字符之前或文件末尾结束；CRLF 序列中的 CR 被视为被忽略的注释文本的一部分。文件末尾的空行注释是有效的。

在块注释中的每个位置，`/*` 打开一个嵌套注释，`*/` 关闭当前注释。否则，消费一个字符作为 [BLOCK_CHAR]。分隔符优先于普通内容，每个开始分隔符都需要一个匹配的结束分隔符。未终止的注释是无效的。

```rust,ignore
// A line comment.
/* outer /* inner */ outer again */
/***/
/* a trailing slash / */
fn main() {}
```

## 文档注释

文档注释，包括外部（`///`、`/** ... */`）和内部（`//!`、`/*! ... */`）形式，根据[测试保证](../01-undefined-behavior/01.00-undefined-behavior.md#test-guarantees)表现出未定义行为。
