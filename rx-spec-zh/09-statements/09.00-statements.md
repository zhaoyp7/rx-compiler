# 语句与绑定

```grammar,statements
Statement -> `;` | LetStatement | ExpressionStatement
```

## 标识符绑定

```grammar,statements
LetStatement -> `let` IdentifierBinding (`:` Type)? `=` Expression `;`

IdentifierBinding -> `mut`? IDENTIFIER
```

`let` 语句将单个标识符绑定到初始化器表达式的求值结果。指定 `mut` 使该绑定可变。初始化器可以产生任何受支持的值，包括由借用表达式形成的引用。

绑定的可见性和遮蔽遵循[名称](../06-names/06.00-names.md#scope-rules)。与可见的非限定常量名冲突的 `let` 绑定会导致未定义行为；参见[常量名冲突保证](../01-undefined-behavior/01.00-undefined-behavior.md#constant-name-collisions)。

可选的类型标注和初始化器表达式受[局部类型推断](../10-types/10.00-types.md#inference)和[强制转换规则](../10-types/10.00-types.md#conversions-and-coercions)约束。对绑定的后续赋值受[赋值目标](../11-expressions/11.04-operator-expr.md#assignment-destinations)约束。

## 表达式语句

```grammar,statements
ExpressionStatement ->
      ExpressionWithoutBlock `;`
    | ExpressionWithBlock `;`?
```

表达式语句对一个表达式求值并丢弃其结果，同时保留其效果。空 `;` 语句没有效果。

[ExpressionWithoutBlock] 需要分号。[ExpressionWithBlock]（`{ ... }`、`if`、`while` 或 `loop`）可以省略分号。

当 [ExpressionWithBlock] 用作语句（其结果被丢弃）时，省略分号要求其求值类型与单元类型 `()` 兼容，或者该表达式必须[发散](../10-types/10.05-never.md)。

相反，当不带分号的 [ExpressionWithBlock] 作为块的最后一个表达式出现时，它充当该块的尾表达式而非表达式语句；它受[尾表达式规则](../11-expressions/11.03-block-expr.md)约束，可以求值为任意类型。

```rust,ignore
fn show(flag: bool) {
    if flag { print_i32(1); }    // unit result: semicolon optional
    if flag { 1 } else { 2 };   // integer result: semicolon discards it
}
```

## 语句边界

在解析表达式语句时，具有外层块形式的表达式会立即终止该语句，而不会贪婪地吞掉任何后续的中缀运算符。在初始化器或其他值表达式上下文中，表达式照常继续。圆括号可以强制进入普通表达式上下文。

附加的 `else` 或 `else if` 子句仍是其 `if` 表达式的一部分，后缀字段访问或方法调用可以在已完成的块表达式之后直接继续。其他表达式语句一直延伸到其终止分号；或者，外层块可以以紧邻闭合 `}` 之前的尾表达式结束。例如，只要 `make()` 返回带有 `value` 字段的结构体，`{ make() }.value;` 就是有效的字段访问表达式语句。

```rust,ignore
let value = if true { 10 } else { 20 } - 1; // initializer is the whole subtraction
if true {} else {} -1;                      // if statement, then -1 expression statement
(if true { 10 } else { 20 }) - 1;           // one expression statement
```

符合规范的编译器必须实现这些语句边界，并遵守上文定义的交法。
