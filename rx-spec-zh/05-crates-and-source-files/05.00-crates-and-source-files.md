# Crate 和源文件

```grammar,items
@root Crate -> Item*
```

一个 Rx 程序由单个源编译单元组成，该单元包含一系列顶层项。它的函数、结构体、常量和固有 impl 共享[名称](../06-names/06.00-names.md)中描述的命名空间。

顶层 [Item] 备选项是 `use` 声明、函数、具名字段结构体、常量和固有 `impl` 块。[Use 声明](../07-items/07.01-use-declarations.md)仅出于 Rust 兼容性而存在，可以在解析后丢弃；它们不会向 Rx 命名空间引入任何名称。项不能在表达式块中声明。程序入口遵循[主函数契约](../15-builtin/15.00-builtin.md#program-entry)。
