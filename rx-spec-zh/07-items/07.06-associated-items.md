# 关联项

r[items.associated.syntax]
```grammar,items
AssociatedItem -> ConstantItem | Function
```

固有 `impl` 块可以包含关联常量、关联函数和方法。

关联函数和方法受[函数与接收者规则](07.02-functions.md#receivers)约束。关联项通过 [PathInExpression] 引用，例如 `Point::new` 或 `Self::LIMIT`。方法调用使用 [MethodCallExpression] 以及[接收者查找规则](../11-expressions/11.10-method-call-expr.md#method-lookup)。
