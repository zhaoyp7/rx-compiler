# 结构体

r[items.struct.syntax]
```grammar,items
Struct -> OuterAttribute* StructStruct

StructStruct -> `struct` IDENTIFIER GenericParams? WhereClause? `{` StructFields? `}`

StructFields -> StructField (`,` StructField)* `,`?

StructField -> IDENTIFIER `:` Type
```

结构体声明定义一个名称、可选的生命周期参数和 where 子句约束，以及以花括号分隔的命名字段列表。字段列表可以在最后一个字段之后包含一个可选的尾随逗号。结构体可以带有[派生属性](../08-traits-and-attributes/08.00-traits-and-attributes.md#attribute-grammar)。

生命周期参数描述存储在结构体中的引用，如 `struct View<'a> { value: &'a i32 }`。类型路径可以用 `View<'a>` 提供相应的实参，或者使用 Rust 允许的生命周期省略。参见[生命周期参数](07.07-generics.md)和[生命周期有效性](../13-references/13.00-references.md#lifetime-validity)。

结构体是一种名义类型，具有显式类型化的命名字段。其字段在整个源代码编译单元中都可访问。[名称规则](../06-names/06.00-names.md#scope-rules)定义了字段唯一性以及 `Self` 在其声明中的含义。例如，在 `struct Node { children: Vec<Self> }` 中，类型 `Self` 指代正在定义的结构体 `Node`。

结构体定义必须具有[有限布局](../10-types/10.00-types.md#recursive-types)。带空花括号的结构体声明（零大小结构体）在语法上是允许的，对零大小数据的操作遵循[零大小数据规则](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)。[后端契约](../16-backend/16.00-backend.md#data-layout)约束实现布局。值通过[结构体表达式](../11-expressions/11.08-struct-expr.md)创建，并通过[字段表达式](../11-expressions/11.11-field-expr.md)访问。

```rust,ignore
#[derive(Clone, Copy, PartialEq, Eq)]
struct Point {
    x: i32,
    y: i32,
}
```
