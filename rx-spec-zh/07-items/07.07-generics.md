# 生命周期参数与约束

## 参数声明

r[items.generics.syntax]
```grammar,items
GenericParams -> `<` (GenericParam (`,` GenericParam)* `,`?)? `>`

GenericParam -> LifetimeParam

LifetimeParam -> Lifetime (`:` LifetimeBounds)?
```

函数、命名字段结构体和固有 impl 可以声明生命周期参数。函数或结构体将 [GenericParams] 置于其名称之后；impl 将列表置于 `impl` 之后。参数列表可以以可选的尾随逗号结尾。每个参数声明一个生命周期，可选地附带存活约束。

```rust,ignore
struct View<'a> {
    value: &'a i32,
}

impl<'a> View<'a> {
    fn new(value: &'a i32) -> Self {
        Self { value: value }
    }

    fn get(&self) -> &'a i32 {
        self.value
    }
}

fn choose<'a>(left: &'a i32, right: &'a i32, first: bool) -> &'a i32 {
    if first { left } else { right }
}
```

生命周期参数在其所声明的项内始终处于作用域中。在 `impl` 块上声明的生命周期也适用于其关联项，不过方法或关联函数可以声明额外的生命周期参数。生命周期名称占据它们自己的命名空间。不正确的生命周期声明、使用或约束是未定义行为；参见[生命周期有效性保证](../01-undefined-behavior/01.00-undefined-behavior.md#lifetime-validity)。

## 生命周期形式与约束

```grammar,types
Lifetime -> LIFETIME_OR_LABEL | `'static` | `'_`

LifetimeBounds -> (Lifetime `+`)* Lifetime?

TypeParamBounds -> TypeParamBound (`+` TypeParamBound)* `+`?

TypeParamBound -> Lifetime
```

诸如 `'a` 这样的命名生命周期指代作用域内的参数。`'static` 表示覆盖整个程序的生命周期。`'_` 表示根据 Rust 的省略规则在该出现处推断出的匿名生命周期。泛型参数声明只接受普通的命名生命周期；`'static` 和 `'_` 只在使用位置有效。

约束 `'a: 'b` 表示 `'a` 比 `'b` 活得更久。诸如 `'a: 'b + 'c` 这样的列表同时给出两个约束。诸如 `View<'a>: 'b` 这样的类型约束表示该类型中包含的引用在 `'b` 内保持有效。这些约束中的类型是由 [Type] 描述的具体类型。

```rust,ignore
fn shorten<'long: 'short, 'short>(value: &'long i32) -> &'short i32 {
    value
}
```

## where 子句

r[items.generics.where.syntax]
```grammar,items
WhereClause -> `where` (WhereClauseItem `,`)* WhereClauseItem?

WhereClauseItem -> LifetimeWhereClauseItem | TypeBoundWhereClauseItem

LifetimeWhereClauseItem -> Lifetime `:` LifetimeBounds

TypeBoundWhereClauseItem -> Type `:` TypeParamBounds?
```

where 子句指定生命周期约束，位于函数的返回类型（若省略则为参数列表）、结构体的生命周期参数或 `impl` 块的目标类型之后。约束以逗号分隔，并允许可选的尾随逗号。生命周期约束可以写在这里，也可以直接写在对应参数的声明上。

```rust,ignore
fn shorten_where<'long, 'short>(value: &'long i32) -> &'short i32
where
    'long: 'short,
{
    value
}
```

这些产生式使用 Rust 的参数列表和约束语法。[GenericParam] 定义生命周期参数；[GenericArg] 定义路径中使用的生命周期和具体类型实参。受支持的命名类型和可调用签名在[路径](../06-names/06.01-paths.md)中规定。
