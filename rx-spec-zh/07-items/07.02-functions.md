# 函数

r[items.fn.syntax]
```grammar,items
Function ->
    `fn` IDENTIFIER GenericParams?
        `(` FunctionParameters? `)`
        FunctionReturnType? WhereClause?
        BlockExpression

FunctionParameters ->
      SelfParam `,`?
    | (SelfParam `,`)? FunctionParam (`,` FunctionParam)* `,`?

SelfParam -> ShorthandSelf

ShorthandSelf -> (`&` Lifetime?)? `mut`? `self`

FunctionParam -> IdentifierBinding `:` Type

FunctionReturnType -> `->` Type
```

函数定义由名称、可选的生命周期参数、参数列表、可选的返回类型、可选的生命周期约束以及必需的函数体组成。顶层函数只接受普通参数，而固有 `impl` 块中的函数还可以包含接收者参数，如下所述。

[GenericParams] 在函数名之后声明生命周期参数。[WhereClause] 在结果类型之后，或当省略结果标注时在参数列表之后，给出生命周期约束。参见[生命周期参数](07.07-generics.md)。

普通参数使用 [IdentifierBinding] 后跟显式类型。函数签名独立于调用者来确定参数和返回类型。接收者或最后一个普通参数之后允许有一个可选的尾随逗号。如果省略返回类型，它默认为单元类型 `()`。

与可见的非限定常量名冲突的普通参数绑定是未定义行为；参见[常量名冲突保证](../01-undefined-behavior/01.00-undefined-behavior.md#constant-name-collisions)。

[名称查找规则](../06-names/06.00-names.md#scope-rules)允许前向调用和相互递归。函数名只能用作调用目标；将函数当作一等值处理会导致[未定义行为](../11-expressions/11.02-path-expr.md#function-values)。[调用表达式](../11-expressions/11.09-call-expr.md)规定实参求值和参数传递；[返回表达式](../11-expressions/11.14-return-expr.md)规定函数返回值。程序入口点在[程序入口](../15-builtin/15.00-builtin.md#program-entry)中定义。

```rust,ignore
fn add(left: i32, mut right: i32) -> i32 {
    right += left;
    right
}
```

## 接收者

在固有 impl 中，第一个参数可以是 [SelfParam]。其形式有：

| 形式 | 接收者 |
| --- | --- |
| `self` | 按值接收者 |
| `mut self` | 可变按值接收者 |
| `&self` 或 `&'a self` | 共享引用 |
| `&mut self` 或 `&'a mut self` | 可变引用 |

带接收者的函数是方法；不带接收者的函数是关联函数。任何后续参数都必须遵循 [FunctionParam] 语法。接收者的生命周期遵循[生命周期有效性规则](../13-references/13.00-references.md#lifetime-validity)，按值接收者遵循[复制/移动语义](../08-traits-and-attributes/08.01-builtin-traits.md#copy)。
