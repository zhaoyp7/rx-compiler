# 常量项

r[items.const.syntax]
```grammar,items
ConstantItem -> `const` IDENTIFIER `:` Type `=` ConstValue `;`
```

常量声明指定一个名称、一个显式类型和一个初始化器。初始化器表达式必须求值为符合[常量上下文规则](../12-const_eval/12.00-const_eval.md)的 [ConstValue]。常量初始化器可以引用其他常量项，但要受相同规则和无环依赖要求的约束。在普通表达式中引用常量会求值为其定义的值。

常量在顶层声明，或作为固有 impl 中的关联项声明。[名称查找规则](../06-names/06.00-names.md#scope-rules)允许前向引用，从而常量可以在其文本声明之前使用。

```rust,ignore
const LIMIT: i32 = 100;
const NEGATIVE: i32 = (-1);
```
