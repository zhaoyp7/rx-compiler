# 实现

r[items.impl.syntax]
```grammar,items
Implementation -> InherentImpl

InherentImpl -> `impl` GenericParams? Type WhereClause? `{` AssociatedItem* `}`
```

固有 impl 为用户定义的命名字段结构体定义关联项。实现中的 [Type] 必须解析为该结构体；指定任何其他类型的目标类型都是编译期错误。包围类型的圆括号保留其标准分组语义；因此，`impl S { ... }` 与 `impl (S) { ... }` 针对同一个结构体。

`impl` 块可以在 `impl` 关键字之后立即声明生命周期参数，如 `impl<'a> View<'a> { ... }`。这些参数在该块的所有关联项中保持有效。方法和关联函数可以声明额外的生命周期参数。左花括号之前的 [WhereClause] 指定生命周期约束。

支持为同一结构体编写多个 `impl` 块。其成员命名空间和重名限制由[名称](../06-names/06.00-names.md#scope-rules)约束。实现块中允许的项在[关联项](07.06-associated-items.md)中定义，方法接收者在[函数接收者](07.02-functions.md#receivers)中描述。

```rust,ignore
impl Point {
    const ZERO: i32 = 0;

    fn total(&self) -> i32 {
        self.x + self.y
    }

    fn translate(&mut self, amount: i32) {
        self.x += amount;
        self.y += amount;
    }
}
```
