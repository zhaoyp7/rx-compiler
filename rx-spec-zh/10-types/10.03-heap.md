# Box 与 Vec 类型

`Box` 和 `Vec` 类型由带 [GenericArgs] 的 [TypePath] 表示。其语法遵循
[类型中的路径规则](../06-names/06.01-paths.md#paths-in-types)；名称解析会解析容器类型名，
该名称要求恰好一个具体类型实参。

## Box 类型

`Box<T>` 是用于一个 `T` 类型值的拥有型容器。`Box` 具有固定大小的表示，
指向为其内容单独分配的堆存储。其构造函数和解引用操作在
[内置签名](../14-heap/14.00-heap.md#builtin-signatures)和 [Box 访问与移动](../14-heap/14.00-heap.md#box-access-and-moves)中描述。

## Vec 类型

`Vec<T>` 是具有运行时长度的 `T` 值拥有型序列。类型实参决定元素类型。序列的元素
占据连续的堆存储，而 `Vec` 值本身具有固定大小的表示。其方法和索引操作在
[内置签名](../14-heap/14.00-heap.md#builtin-signatures)和 [Vec 操作](../14-heap/14.00-heap.md#vec-operations)中规定。

## 类型实参与组合

类型实参可以是任何受支持的具体类型，包括另一个容器、数组、引用或具名结构体。`Box` 和 `Vec` 可以出现在任何接受 [Type] 的地方。[零大小数据规则](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)约束元素类型和所指类型。

<details>
<summary>组合示例</summary>

| 类型写法 | 含义 |
| --- | --- |
| `Box<i32>` 或 `Box::<i32>` | 一个拥有的整数 |
| `Vec<u32>` | 无符号整数序列 |
| `Box<[i32; 4]>` | 一个拥有的四元素数组 |
| `Vec<Box<i32>>` | 拥有的整数 Box 序列 |
| `Box<Vec<i32>>` | 一个拥有的向量 |
| `Vec<&i32>` 或 `Vec<&'a i32>` | 共享引用序列 |
| `Vec<View<'a>>` | 带生命周期实参的结构体序列 |
| `&mut Vec<Box<i32>>` | 指向 Box 向量的可变引用 |
| `[Vec<i32>; 2]` | 两元素向量数组 |
| `Vec<Vec<i32,>,>` | 带尾随类型实参逗号的嵌套向量 |

```rust,ignore
struct Storage {
    values: Vec<Box<i32>>,
    counts: Box<[i32; 4]>,
}

fn append(values: &mut Vec<Box<i32>>, value: Box<i32>) {
    values.push(value);
}
```

</details>

[递归类型规则](10.00-types.md#recursive-types)定义了容器间接性如何允许有限的递归布局。生命周期实参遵循[生命周期规则](../13-references/13.00-references.md#lifetime-validity)。未加注解的局部变量的容器类型从其初始化表达式推断，但[绝不由后续语句推断](10.00-types.md#inference)。

容器值由[内置构造函数](../14-heap/14.00-heap.md#builtin-signatures)创建。
