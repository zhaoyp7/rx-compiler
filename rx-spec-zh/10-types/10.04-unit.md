# 单元类型

```grammar,types
UnitType -> `(` `)`
```

单元类型写作 `()`，其唯一的值由 [UnitExpression] 描述。

其有效的数据用途以及函数/控制流结果的例外情况由[零大小数据规则](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)定义。

```rust,ignore
fn do_nothing() -> () {
    // A function with an omitted or () return type returns ()
}

();                              // Unit literal
```
