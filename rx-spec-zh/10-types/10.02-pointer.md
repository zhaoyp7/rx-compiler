# 引用类型

```grammar,types
ReferenceType -> `&` Lifetime? `mut`? TypeNoBounds
```

引用类型以 `&` 开头，后跟可选的 [Lifetime]、可选的 `mut` 以及被引用的类型。例如 `&i32`、`&'a i32`、`&'a mut Vec<i32>` 和 `&'_ i32`。

共享引用和可变引用是不同的类型。结构体字段使用这些相同的引用形式。生命周期注解与省略遵循[生命周期有效性规则](../13-references/13.00-references.md#lifetime-validity)；测试保证这些规则以及借用有效性成立。仍需要进行普通的类型检查与位置可变性检查。

在类型上下文中，`&&T` 通过对 `&&` 词法单元进行上下文拆分，被解析为两个嵌套的引用类型构造器。同一规则递归地适用于数组类型内部以及 `Box` 和 `Vec` 的类型实参中。

```rust,ignore
let r: &i32 = &x;              // shared reference
let m: &mut i32 = &mut x;      // mutable reference
let nested: &&i32 = &r;        // parsed as &(&i32) via contextual splitting of &&
```
