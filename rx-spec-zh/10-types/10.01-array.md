# 数组类型

```grammar,types
ArrayType -> `[` Type `;` ConstValue `]`
```

数组类型指定一个元素类型和一个 [ConstValue] 长度。元素类型可以是任何受支持的具体类型。长度类型化遵循[常量上下文](../12-const_eval/12.00-const_eval.md#typing-and-range)，数组类型的相等性遵循[类型同一性](10.00-types.md#supported-types)。

语法上允许零长度，但对访问零大小数组数据的表达式进行求值会表现出[未定义行为](../01-undefined-behavior/01.00-undefined-behavior.md#zero-sized-data)。参见[类型与类型推断](10.00-types.md)和[常量上下文](../12-const_eval/12.00-const_eval.md)。

```rust,ignore
let buffer: [u32; 16] = [0u32; 16];      // array of 16 u32 values
let matrix: [[i32; 4]; 4] = [[0; 4]; 4]; // 4x4 nested array of i32 values
```
