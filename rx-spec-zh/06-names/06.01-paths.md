# 路径

路径通过以 `::` 分隔的段来命名值、类型或关联项。类型路径和表达式路径共享相同的泛型参数语法（[GenericArgs]）。

[Use 声明](../07-items/07.01-use-declarations.md)出于 Rust 兼容性具有单独的 [UsePath] 语法。它们的路径不由 Rx 编译器解析，也不扩展这里定义的类型或表达式路径。

## 表达式中的路径

```grammar,paths
PathInExpression -> PathExprSegment (`::` PathExprSegment)*

PathExprSegment -> PathIdentSegment (`::` GenericArgs)?

PathIdentSegment -> IDENTIFIER | `self` | `Self`
```

表达式路径在泛型参数之前使用 `::`（'turbofish' 语法），如 `Box::<i32>::new`。它们的最后一个段可以命名值或关联项。对这些路径的调用受 [CallExpression] 和 [MethodCallExpression] 约束。

## 类型中的路径

```grammar,paths
TypePath -> TypePathSegment (`::` TypePathSegment)*

TypePathSegment -> PathIdentSegment (`::`? GenericArgs)?
```

类型参数可以直接跟在段之后，也可以跟在 `::` 之后，因此 `Box<i32>` 和 `Box::<i32>` 命名同一类型。引用用户定义结构体的类型路径可以提供生命周期参数，例如 `View<'a>`，或依赖允许的生命周期省略。

## 泛型参数

```grammar,paths
GenericArgs -> `<` GenericArgList? `>`

GenericArgList -> (GenericArg `,`)* GenericArg `,`?

GenericArg -> Lifetime | Type
```

泛型参数以逗号分隔，并允许可选的尾随逗号，任何生命周期参数都必须位于类型参数之前。在有效程序中，`Box` 和 `Vec` 恰好有一个显式的具体类型参数。在 `Box::new(...)` 或 `Vec::new()` 构造函数调用中省略它属于[未定义行为](../14-heap/14.00-heap.md#builtin-signatures)。用户定义的函数和结构体只接受其声明的生命周期参数，而原始类型不接受任何泛型参数。泛型参数数量或种类的任何其他不匹配都是编译错误；生命周期正确性受[生命周期有效性保证](../01-undefined-behavior/01.00-undefined-behavior.md#lifetime-validity)约束。

类型参数可以递归地包含任何受支持的具体类型。例如：

```rust,ignore
let values: Vec<Box<[i32; 4]>> = Vec::<Box<[i32; 4]>>::new();
let borrowed = Vec::<&'a i32>::new();
```

## 路径解析

| 路径角色 | 解析形式 |
| --- | --- |
| 值 | 绑定、常量、函数或 `self` |
| 类型 | 原始类型、声明的结构体、`Self`、`Box<T>` 或 `Vec<T>` |
| 关联项 | 结构体路径或 `Self`，后跟已声明的成员或派生的内置方法 |
| 内置关联操作 | `Box::<T>::new`、`Vec::<T>::new`，或类型路径上受支持的内置方法，例如 `Box::<i32>::clone` |

函数和方法可以在 Rust 允许的地方使用显式生命周期参数。省略的生命周期使用受支持的 Rust 2021 推断和省略规则。测试保证显式生命周期参数（包括早绑定和晚绑定用法）是有效的。

未解析的名称是编译错误。名称解析后，调用表达式会根据参数和接收者规则进行检查。提供不正确的生命周期参数或无效的生命周期省略，根据[生命周期有效性保证](../01-undefined-behavior/01.00-undefined-behavior.md#lifetime-validity)，会导致未定义行为。
